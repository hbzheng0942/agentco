## 总览

**3D 世界模型路线仍处于"演示有余、可玩性不足"阶段。** World Labs Marble 是唯一进入早期商业化（$95/月定价、public API、Autodesk $200M 战略投资）的玩家，但其实际可玩证据仅限 web viewer 和爱好者级别的 chrome 小游戏；腾讯 HunyuanWorld 2.0（2026-04）以开源姿态追赶，但本批 raw 缺乏其社区采纳与性能数据。行业共识（Ars Technica 2026-07-13 综述）认为"what's still unsettled"——持久一致性、实时交互帧率、物理仿真仍是未解瓶颈。信号数量 22 条，最高评分 4。

## 信号分层

### 簇一：World Labs Marble — 3D 路线的商业化先锋
- **so-what**：唯一有定价、API 和大厂资本背书（Autodesk）的 3D 世界模型产品，但可玩性证据薄弱，距离"游戏引擎插件/运行时"尚有 gap。
- World Labs 发布 Marble 有限访问 beta，支持从文本/图像/视频/粗 3D 布局生成世界，并支持交互式编辑、扩展与组合 [worldlabs.ai, 2025-11-12](官方发布) [PUSH]
- TechCrunch 报道 Marble 为 World Labs 首个商业产品，与 Odyssey/Decart/Genie 差异在于生成"持久、可下载的 3D 环境"而非探索时即时生成 [techcrunch.com, 2025-11-12](主流媒体)
- Reddit 早期反馈（2025-07）指出 Marble 当时"只有 web-based viewer 作为 demo"，尚无完整可玩游戏 [reddit.com, 2025-07-14](社区)
- HN 用户基于 Marble 世界开发了 chrome extension 小游戏（寻找 labubu），▲15·25 评论，说明社区已开始实验性游戏化 [akadeb.xyz, 2025-10-09](社区)

### 簇二：资本与生态接口信号
- **so-what**：Autodesk 入局验证 3D 世界模型在 AEC/娱乐工作流中的商业价值，但"与 Autodesk 工具集成"的具体接口与游戏引擎无关。
- Autodesk 对 World Labs 战略投资 $200M，探索 World Labs 模型与 Autodesk 工具的双向集成，首批聚焦娱乐用例 [autodesk.com, 2026-02-18](官方发布) [PUSH]
- Reddit 提及 World Labs 于 2026-01 发布 public API [reddit.com, 2026-02-21](社区，未独立证实)
- Forbes 报道 World Labs 以 $1B 赌注推进空间智能 [forbes.com, 2026-03-06](主流媒体)

### 簇三：中国玩家 — 腾讯混元 3D 世界模型
- **so-what**：腾讯以开源（GitHub）+快速迭代（1.5→2.0）追赶，但本批缺乏其性能基准、社区 star 数和实际可玩 demo 的独立印证。
- 腾讯 HunyuanWorld 2.0 于 2026-04-16 发布，宣称 SOTA 3D world model [github.com/Tencent-Hunyuan/HunyuanWorld-1.0](官方发布)
- 第三方博客指出腾讯与阿里同日发布世界模型，HunyuanWorld 1.5 此前为"视频而非 3D 几何"，2.0 明确转向 3D [buildfastwithai.com, 2026-04-16](行业媒体)
- **注意**：GitHub 条目 date 为 (undated)，发布日期仅凭摘要中"April 16, 2026"推断。

### 簇四：行业综述与基准
- **so-what**：学界/媒体共识是世界模型概念尚混乱，缺乏统一评估框架；Blueprint Bench（2026-05）首次尝试给 LLM 的 3D 空间智能打分，但与世界模型游戏的直接关联弱。
- Ars Technica 近期综述（2026-07-13）指出世界模型"前景与限制并存"，专家共识多议题仍 unsettled [arstechnica.com, 2026-07-13](主流媒体)
- 李飞飞（World Labs 创始人）发布世界模型功能分类学（Renderers/Simulators/Planners），试图建立分析框架 [drfeifei.substack.com, 2026-06-03](自媒体/创始人)
- Blueprint Bench（2026-05-04）首次评估 LLM 的 3D 空间智能能力 [andonlabs.com, 2026-05-04](行业媒体)
