## 0. 一句话定位

**给机器人仿真团队一条"文/图 → 可运动、可验证、可导入引擎的铰接资产"流水线。**
差异化钉死在:关节语义正确性 + 物理验收闭环 + 仿真格式可用(MJCF/USD Physics,URDF 降级)。
竞争窗口按 **6 个月下限**规划(battle O10:窗口证据薄,Tripo 距"绑骨→URDF 导出"仅一个功能发布)。

## 1. 用户、问题与价值轴

首用户:机器人仿真/具身智能团队。现状:手转 CAD→URDF/MJCF 小时级且易错;PartNet-Mobility ~2.3k
物体品类窄、多样性不够域随机化;学术方案无可用性工程。

**价值轴(v0.3 改述,battle O2)**:不是单轴"提速",是 **正确性 × 多样性 × 可随机化 @ 可接受吞吐**。
对应两类业务指标:相对伙伴自定义基线的提速(基线协议写死在 MOU:伙伴工程师现有工作流做同规格资产
n=5 计时,W2 完成)+ **可交付多样性**(合法品类数 × 品类内参数变体数)——后者是对
"下载 PM 库免费且即时"这一真实替代品的差异化答卷。

一期刻意不做:功能打印(公差生死线顺延二期)、通用美术资产、场景级生成。

## 2. 产品形态原则

**能力脊柱先行,画布形态 TBD**(HB 已定)。管线天然分阶段、产出结构化带 hash,画布是未来渲染层。
一期唯一承诺的交互是**结构确认环节**(必须 AI-powered):

- 2D 层级视图:部件树 + 零部件关系(父子/接触/传动)+ 关节语义标注,逐项可改;
- **top-3 多方案确认,强制多样化**(battle O5):候选沿**部件粒度轴**(粗/中/细部件树)分化
  ——恰是仿真任务的真实分歧维度;方案两两距离(功能等价度量下)设下限,不达即重采;
- 低置信字段高亮(LLM 与关节预测器交叉校验的分歧项),辅助用户在**没有真值**时把对的挑出来
  ——在线考的是盲选,不是离线的 pass@3(§4.3)。

## 4. 一期 Deep-dive

### 4.0 前置门(W0-W1,过不了不开工)——battle O1/O2/O12 最重裁决

一期最大存在性风险不是"做不出",是"做出来没人要"。需求存在性验证**前置于管线建设**:

- **客户发现**:3-5 个仿真团队访谈,确认"铰接资产获取"在其瓶颈清单的位次(若普遍排在接触动力学
  保真度/随机化规模之后,方向重估)、确认切换意向、各自定义基线;
- **签约门**:≥1 家伙伴签 **real-task LOI**(准入标准:有在跑的具身训练任务、有资产采购/自建预算迹象、
  承诺 W7 前把资产集成进真实训练 run)+ 1 家观察员对照;
- **concierge 探针**(W1-2,≤1 人周):人工(现有工具+手标 ASG)做 10 个完美资产白送伙伴,
  看是否真进本周训练 run、是否回头要更多——连手工完美资产都不用,管线做出来也没人用;
- **门槛**:LOI 签下 + concierge 资产被真实使用 → 开工;任一不成 → 一期暂停,回 Strategist 重开方向 battle。

### 4.1 黄金评测集(分期建,先解锁后补全)——battle O3/O6/O7

- **v0(W2,解锁 M1)**:30-40 例,PM 派生单品类(柜体),真值来自数据集标签,标注成本近乎零;
- **v1(W6)**:PM held-out 扩到 **150-200 例**(真值免费,扩样保统计功效)+ 真实产品图 30 例 +
  纯文本 30 例(人工标注流 W4 汇入);负样本 50 例(真值 ASG 程序化变异:反轴向/错限位/错类型/穿模);
- **一切指标分切片报数并附 CI**,禁止聚合粉饰;frozen set 与伙伴失败样例的 live set 分开报;
- 真实图/文本切片是"文/图→"承诺的诚实考卷;PM 切片仅作天花板参照与裁判校准。

### 4.2 ASG 功能等价判定器(指标地基,先于主线指标)——battle 并入项 M1

ASG 不唯一(同一柜体有多个合法部件分解),对单一真值算树编辑距离会误判合法替代方案。定义
**功能等价**:运动学图同构(允许部件合并/细分)∧ 关节参数在容差内(轴向角差/限位区间 IoU)
∧ harness 行为一致(同驱动信号下运动包络匹配)。pass@k、编辑距离、方案多样性距离**全部由
等价判定器裁定**;判定器与 harness 同受 §4.5 校准协议约束。副产品:标注者只需给出任一合法 ASG,
消解标注歧义。

### 4.3 主线 A:ASG 结构理解(文/图 → top-3 结构方案)

管线:品类模板先验 → VLM/LLM 结构化输出 top-3(粒度轴强制分化)→ 图像路径辅 P3-SAM 分割证据
→ 关节参数第二意见(Real2Code/URDFormer 类)→ 交叉校验分歧标低置信。

**离线指标(黄金集分切片,周报附 CI)**:

| 指标 | W6 线(仅柜体切片,只杀不放行) | W10 线(分切片) |
|------|------|------|
| 结构 pass@1(等价判定) | ≥40% | ≥60%(PM)/≥45%(真实图/文本) |
| 结构 pass@3(等价判定,必要非充分) | ≥70% | ≥85%(PM)/**≥65%(真实图/文本)** |
| 关节类型准确率 | ≥85% | ≥93% |
| 轴向误差中位数 | ≤15° | ≤8° |
| 限位区间 IoU 中位数 | ≥0.6 | ≥0.8 |
| top-3 方案两两等价距离 | ≥下限(spec 定值) | 同左 |

**在线指标(伙伴试点 W7-10)**:**盲选命中率**(用户无真值选中等价正确候选)≥70%;
3 选 1 采纳率 ≥50%(<50% 即触发 §4.8);修正次数中位数 ≤3;单结构确认 ≤3 分钟。
修正集中度仅作描述性统计(battle O13:一期下游无交互点,该指标不可能不成立,不承载验证声称;
"便宜阶段修正"的真检验 = 下游返工率,移二期)。

**错误分类学** E1-E7 逐周归因;迭代/切换决策不读周间波动,用**预注册效应量 + CI + 滚动口径**(§4.8)。

### 4.4 主线 B:接口方案(参数化接口件库 + 装配)

- 接口词汇表 v0(五品类:合页/销轴/滑轨/转轴+轴孔/卡扣),含参数域、布尔/配准规则、MJCF/USD 映射;
- **词汇表覆盖率 ≥95%**(黄金集全部关节可被模板表达;<80% 是 D3 品类结构性警报);
- **外壳尺度 grounding 为一期显式工作项**(battle O8:mesh 无尺寸语义,不锚定则与参数化件布尔必然错位):
  从品类模板取参考尺寸赋予外采 mesh;gen-API 打样验收从"外观质量"扩到**"可赋参考尺度并与接口件布尔通过"**;
- 装配成功率 **95% 为待测目标非承诺**,失败按"尺度错 vs 几何错"归因;一期配准是参数化件驱动的
  碰撞级配合(D2 铁律下配合几何永远由参数化件承载),**不是**二期 G2 的 mesh↔B-rep 对齐,真公差明确出界。

### 4.5 裁判:物理验收 harness(先校准、持续复检、审优分离)——battle O4

- 实现:MuJoCo headless 为主,SAPIEN 数据侧交叉;验收项 = 全行程运动/限位不穿模/无非预期碰撞/
  传动成立/惯量碰撞体合法;
- **校准协议(W2)**:真值集 false-reject ≤10%;负样本集 **false-accept ≤5%(不谈判红线)**;
- **周复检(v0.3 新增)**:每周在冻结负样本上复跑 false-accept,漂移即独立 tripwire;
- **审优分离**:校准/审计 harness 与优化 ASG 管线由不同 agent 承担,auditor 域周审交叉核
  (三审分离的延伸——北极星与守门指标不许同一只手既优化又执法);
- ZTR 同时报**保守下界**(扣除 false-accept 上界);harness 版本随 ZTR 锁定,裁判变更必须重跑基线。

### 4.6 飞轮(诚实版)与合成数据预研——battle O11

correction event schema 不变:`(task_id, 阶段, error_class, field, from→to, 耗时, actor)`。
**一期定位(范畴纠正)**:主线 A 推断模型的训练/评测料 + 黄金集 live 补给 + H3 交互假设度量。
**明确不是** L3(关节参数→几何)配对样本——L3 数据主力是程序化合成(§3 风险 2),
故新增 `spec-synth-data-scoping`(light,M2 并行):Infinite Mobility 可得性核实 + 自建引擎成本估,
产出直接喂 H1 立项裁决。飞轮近期价值按真实量级讲(1 伙伴×几十资产 = 评测补给,不是护城河)。

### 4.7 北极星与 go/no-go(W10 裁决口径,分切片)

- **北极星:非 PM 切片 ZTR ≥60%**(真实图/文本,兑现"文/图→"承诺的诚实口径);
  PM 切片 ZTR ≥70% 作天花板参照;同时报 harness 保守下界;
- 守门:false-accept ≤5% 且周复检无漂移;
- 结构 pass@3 分切片达标(§4.3);词汇表覆盖率 ≥95%;
- 业务:伙伴真实任务采用 ≥20 资产 + **W7 集成度前导信号**(资产是否已进训练 run——用于 W10 失败归因:
  产品不行 vs 伙伴滑坡);相对 MOU 基线提速达标;可交付多样性(品类×变体)报数;
- 成本/时延:单资产外采成本 ≤$1、结构出稿 ≤30s、端到端 ≤10min。

### 4.8 掉头触发器(预注册:单阈值 + 时间盒,无主观 AND 逃生舱)——battle O12

| 触发器(时间盒) | 阈值(预注册) | 动作 |
|------|---------|------|
| 前置门(W1) | LOI 未签 或 concierge 资产未被真实使用 | 一期不开工,回 Strategist 方向 battle |
| W6 柜体 checkpoint(**只杀不放行**) | pass@3 <50%(等价判定,CI 下界口径) | 启动掉头 A 评估;达标≠对 5 品类放行(battle O9),W6 前引入第 2 品类骨架级泛化早探 |
| 词汇表(W8) | 覆盖率 <80% | 掉头 B:D3 品类回炉或收窄 2-3 品类做深 |
| 伙伴需求(W7) | 资产未进任何真实训练 run | 掉头 C 评估(程序化资产库+随机化 API)或停 |
| 结构卡交互(W10) | 3 选 1 采纳率 <50% 或盲选命中 <70% | 结构卡降级单方案+逐字段置信度;画布方向存疑记入二期 battle |
| harness 漂移(周) | false-accept 周复检 >5% | 全链路指标冻结,先修裁判 |
| 预算/编制(持续) | M0 就绪门未按时完成(其本身即 no-go 信号)或关键编制缺口 | 资源掉头,范围再砍,不延总周期 |

掉头 A(导入已有 mesh/CAD + 自动加铰接)**降级为"待验证兜底"**(battle O12c:仿真团队常常正因
没有现成模型才卡住):触发时先做需求压力测试(存在"有模型卡铰接"的用户群才执行),否则另开 battle。
