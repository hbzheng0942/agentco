## 总览

本轮补抓三条精炼 query 后的核心判断：**世界模型三大玩家（Odyssey/Marble/Hunyuan）的最新信号都偏向资本与姿态层，距离"游戏引擎可用的 3D 世界模型"仍有工程断层。** Odyssey 拿到 $1.45B 估值（Amazon 领投）是本期最强资本信号，但其可玩 demo（90 年代 Nintendo 风格射击游戏）更像 curated 体验而非通用能力；Marble→Unreal 导出仅靠第三方高斯泼溅插件（Akiya），无原生 Unity/UE 集成，无 glTF/USD 导出提及；HunyuanWorld 2.0 以开源姿态发布但社区信号几乎为零（唯一 community patch ⭐0）。信号总量 26 条，最高影响评分 4（Odyssey 融资）。

## 信号分层

### 簇一：Odyssey — 融资封王但产品证据未同步跟进

- **so-what**：$1.45B 估值确认资本市场将"世界模型"列为 LLM 之外的下一个 AI 赛道，但 Odyssey 自 2025 年首次 demo 以来，2026 年的唯一可玩证据是一个 90 年代风格射击游戏，其通用世界模型能力边界未明。

- Odyssey 获 Amazon 等机构 $310M 投资，估值 $1.45B，TechCrunch 称"world models are the next big thing in AI beyond LLMs" [techcrunch.com, 2026-06-17](主流媒体) + [ft.com, 2026-06-17](主流媒体) → 多源相互印证 [PUSH]
- 2026-05 发布可玩 demo：90 年代风格的 Nintendo 射击游戏 [superhuman.ai, 2026-05-20](行业媒体) — 属于 curated 体验，非通用 3D 世界生成证明
- Odyssey 官网仍定位"general world models: causal, multimodal systems that learn to understand and simulate the world" [odyssey.ml, (undated)](官方发布)
- 原始世界模型 streaming demo（每 40ms 视频帧预测）发布于 2025-05-28，距今 >13 个月，无产品迭代证据 [techcrunch.com, 2025-05-28](主流媒体) → 时效衰减

### 簇二：World Labs Marble — 引擎集成仅靠三方插件，Unity 路线全缺

- **so-what**：Marble 虽有 public API 与生产管道导出指南，但其"游戏引擎集成"实际 ≈ 高斯泼溅导入 Unreal（第三方付费插件 Akiya），无 Unity 支持，无 glTF/USD 原生导出——距离"世界模型作为游戏引擎组件"的愿景差一个标准化层。

- World API 发布（2026-01-23），支持从文本/图像/视频生成可探索 3D 世界 [productcool.com, 2026-01-23](行业媒体) — 但无 API 调用量与采纳率数据
- Marble→Unreal 导出文档存在，但依赖第三方插件 Akiya（单次付费），非原生集成；路线是高斯泼溅→Unreal，无标准几何导出 [docs.worldlabs.ai, (undated)](官方发布)
- Marble 网格导出到生产管道已有一份指南，涉及几何清理、贴图、优化 [skywork.ai, 2025-11-16](行业媒体) — 适合 VFX 离线渲染，非实时游戏管线
- Reddit 讨论 Marble 生成 3D VR 世界 "using a single image to create a walkable 3D render that can export as a gaussian splat" [reddit.com/r/OculusQuest, 2025-10-17](社区) — 时效衰减
- **关键缺口**：无 Unity 插件，无 glTF/USD/FBX 标准导出格式证据，无实时帧率/交互延迟数据

### 簇三：Tencent Hunyuan HY-World 2.0 — 开源姿态明确但社区采纳未验证

- **so-what**：腾讯以 Apache 2.0 大力推开源（含 Hy3 模型许可证改为 Apache 2.0），但 HY-World-2.0 的 GitHub 社区信号近乎空白——唯一 community 贡献是 ⭐0 的 Windows 部署脚本，说明个人开发者采用门槛尚高。

- HY-World-2.0 代码仓库发布（2026-05-27），支持多模态 3D 世界：3DGS + 网格双输出；WorldMirror 2.0 重建 [github.com/Tencent-Hunyuan/HY-World-2.0, 2026-05-27](官方发布)
- 技术博客确认 HY-World 2.0 输出显式 3D（mesh + 3DGS），区别于"纯像素视频"的世界模型路线 [explainx.ai, 2026-05-06](行业媒体)
- Community Windows/Blackwell 部署脚本，⭐0 [github.com/mikecaronna, 2026-05-21](社区) — 实际采用率趋近于零
- Tencent Hy3（不同模型系列）许可证改为 Apache 2.0 [digg.com, 2026-07-06](聚合媒体) — 显示腾讯整体开源立场但非 HY-World 2.0 的直接信号

### 簇四：跨引擎工具链 — 边缘但提示行业痛点

- **so-what**：Unreal↔Unity 的资产互通仍然是痛点，第三方 Exporter 的存在提示「如果世界模型要入游戏引擎，标准化资产交换层（glTF/USD）是关键前提而非可有可无」。
- Unreal→Unity 跨引擎环境导出工具（2026-06-14），解决 UV 断裂与材质丢失问题 [thedevsupply.com, 2026-06-14](行业媒体)
