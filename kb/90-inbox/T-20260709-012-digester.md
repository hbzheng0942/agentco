## cross_cutting

### 贯穿性方法论
1. **AI=工具,非魔法**:全视频核心哲学。AI用于它擅长的(资产生成/逻辑编码),不用于它慢的(3D空间放置/视觉判断)。"I treat AI as a tool. So, I going to use AI as much as it makes sense." [01:00]
2. **大件优先→细节迭代**:"start with big parts" [09:02] + "build a part → it started to make sense → the next part is easier" [14:05] — 渐进式满足感驱动动机
3. **路径先于地形**:"build a walk passes first... and then I build the rock around it" [13:04] — 可玩性先于视觉
4. **精确prompt > 模糊prompt**:"tell more details and expect the result will be more accurate" [27:40];模糊→"will spend way more tokens because it will need to do a screenshot" [28:10]

### 快捷键/操作体系
- Blender: Edit Mode / Proportional Editing / Knife Tool (K) / Sculpt Mode + Elastic Grab brush / E(extrude) / Collections
- Asset Hub: 批量多资产生成(同类放一起一次prompt)
- Unreal Engine: Third Person Template / Animation Retarget / Physics Asset / Animation Graph

### 反模式/陷阱
1. **硬表面AI建模**:AI生成硬表面形状不准→手工建primitive+AI纹理 [12:04]
2. **AI做3D放置**:Claude Code等模型"not that good at vision... that better is insignificance for tasks like this" [19:07] — 不要浪费时间让AI做它不擅长的事
3. **碰撞体部署后必验证**:碰撞误挡路径是常见bug,需跑图验证 [25:09]
4. **lever给AI慢**:简单3D编辑(分离部件/设原点)手工1分钟的事,AI反而耗时 [23:09]

### ASR已知问题
- 全文"Cloth"/"Cloth Cloth" = "Claude"/"Claude Code"(自动字幕mangling)
- "WBE" = Unreal MCP add-on名称(上下文确认,非ASR错误)
