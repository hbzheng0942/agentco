# E2 · 世界模型→游戏（视频路线）Landscape 扫描

## 总览

视频路线世界模型已从纯研究进入早期产品化阶段，但3个可确认的玩家（Genie 3 / Happy Oyster / PixVerse R1）均未报告可玩性/交互时延/记忆时长等硬指标，且最核心的竞争者（Odyssey、Decart/Oasis）在本批原料中完全缺失。本批信号离散，未见单个玩家形成产品-市场收敛信号——当前视频路线全球处于"demo 可试但离可玩游戏还很远"的阶段。

---

## 信号分层

### 簇1：Google DeepMind Genie 3 → Project Genie（路径先行者）

**So-what**：唯一从研究论文走到付费订阅产品的世界模型，但距离游戏可玩还有质的差距。

- Genie 3 2025-08 发布：文本→交互式 3D 世界，24fps、720p，一致性维持"几分钟" [deepmind.google/blog, 2025-08-05](可信度:官方发布); 多源相互印证（RD World Online、Fenxi.fr 详情、YouTube 官方视频均同一事件）
- Project Genie 于 2026-01-29 向美国 Google AI Ultra 订阅者开放试用 [blog.google, 2026-01-29](可信度:官方发布) —— 世界模型首次进入付费产品形态
- 资本市场影响信号：Genie 发布后 Take-Two 股价曾单日跌 7.9%，表明市场将其视为对传统游戏厂商的潜在威胁 [reddit r/GTA, 2026-02-14](可信度:社交媒体)

**影响评分：3/5**。研究→产品化是重要转折。但 6 个月无新能力更新，且仅限美国 Ultra 订阅者（$20+/月），非游戏场景面向——Playability/时延等指标未知。若 Project Genie 未在 2026 下半年推出 API 或扩大访问范围，则产品影响力有限。

### 簇2：Alibaba Happy Oyster（中国大厂入局）

**So-what**：首个获独立媒体上手评测的国产实时世界模型产品，但当前是"技术展示"而非游戏引擎。

- Happy Oyster 1.0 于 2026-04-16 发布，文本/语音/图像→实时交互式 3D 环境，支持连续影音生成 [Bloomberg, 2026-04-16](可信度:主流媒体); [happyoyster.cn/gallery](可信度:官方产品页)
- GIGAZINE 2026-06-18 上手评测确认产品可体验，评价为"就像在电子游戏中一样"，但明显是早期版本 [GIGAZINE, 2026-06-18](可信度:行业媒体)
- 多个信息来源（Bloomberg / Yicai Global / tellers.ai）均报道同一次发布，非多源验证

**影响评分：3/5**。有独立上手评测的产品 = The bar 高于纯 demo，但距离可玩游戏（物理一致性、交互精准度）还有相当距离。若 Happy Oyster 半年内无开发者 API 或引擎集成方案，则停留于展示层。

### 簇3：PixVerse R1（实时视频世界模型）

**So-what**：最新（2026-06）发布的产品，但仅公司自述，无独立验证。

- 2026-06-28 发布 PixVerse R1：实时无限交互视频生成，"instant response to user input" [pixverse.ai/blog, 2026-06-28](可信度:公司博客); 产品页 world.pixverse.ai/generate 号称"continuous visual streams that respond instantly to user input"
- 目前仅有公司自述，无第三方评测或上手体验
- 爱诗科技（PixVerse）背景：中国 AI 视频生成创业公司

**影响评分：2/5**。最近期（<30天）的信号，发布者有既有视频产品。但完全无独立验证——等待独立评测后重新评估。

## 缺口与矛盾

### 检索盲区
搜索原料中**完全缺失**以下对 E2 路线至关重要的玩家：
- **Odyssey（Wayne AI）** — 以自动驾驶世界模型起身，2024-2025 转向面向游戏的可交互真实世界模型，号称极高视觉保真度。本批 query 未覆盖。
- **Decart / Oasis** — 2024 年以来第一款可玩的实时生成式游戏 demo（Minecraft 风格），曾引发广泛讨论。仅在 worldsimulator.ai 榜单中被提到名称，无任何实质信息。
- **Lingbot（零一万物/灵境智元？）** — 身份完全无法确认，搜不到任何产品/公司/团队信息。
- **Matrix-Game** — 未抓到任何信息，可能为项目代号或研究原型。
- **所有玩家的融资/团队动向** — 本批 raw 无任何融资或团队背景信息。Genie 3（DeepMind 内部项目），Happy Oyster（Alibaba），PixVerse（爱诗科技）均为已有主体，但具体投入规模未知。

### 信号冲突
无实质性矛盾——因为硬指标（时延/一致性/记忆时长）所有玩家**都没有披露具体数字**。Genie 3 的"few minutes consistency"被多处引用但没有更细的数据（多久会崩？崩后行为？）。Happy Oyster 的手感描述只有 GIGAZINE 的主观评价。

### 时效警示
本批最新信号为 PixVerse R1 发布（2026-06-28），距今 ≤30 天。但 Genie 3（2025-08）已 >11 个月，Project Genie 产品化（2026-01）已 >5 个月。两家中国玩家的时效较好（Happy Oyster 上手评测 2026-06-18，PixVerse R1 2026-06-28）。
