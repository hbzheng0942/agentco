- **output**: 无材质纯几何体
- **accept**: 模型显示为纯色 smooth shading,纹理不可见
- **fail_modes**: ∅

### S2 · Clear Sharp Edges

- **tool**: Blender / Edit Mode → Edge Mode
- **ops**:
  1. 进入 Edit Mode [03:31]
  2. 切换到 Edge selection mode [03:31]
  3. 按 `A` 全选 [03:31]
  4. 右键 → **Clear Sharp** [04:01]
- **input**: 带 sharp edge 标记的 imported mesh
- **output**: 所有 edge sharp 标记清除
- **accept**: 模型渲染为平滑着色,无硬边瑕疵
- **fail_modes**: 若跳过 → 模型渲染会出硬边伪影
- **rationale**: "so our model is rendered properly" — sharp edges 在 sculpting 前必须清理,否则光滑几何体上会残留硬边 [04:01]

### S3 · Remesh (Density Up)

- **tool**: Blender / Sculpt Mode → Remesh (menu: Remesh)
- **ops**:
  1. 进入 Sculpt Mode [04:01]
  2. 设置 Voxel Size = `0.02`(本示例;视模型尺寸调整) [04:31]
  3. 按 Remesh 按钮,等待计算 [04:31]
  4. **验收测试**: 用 Clay brush 在表面画一笔 → 判断:
     - 笔触**平滑** → 分辨率够 → ✅ 继续
     - 笔触**太光滑/顶点太多/操作卡顿** → Voxel Size **调大**(数字增大) [05:01]
     - 笔触**不够光滑** → Voxel Size **调小**(数字减小) [05:01]
- **input**: 低面数 AI 导出 mesh(面数不足 sculpting)
- **output**: 面数充足的均匀网格,笔触平滑
- **accept**: Clay brush 一笔画下去,geometry 边缘平滑无锯齿(原话: "if the result is smooth, then probably the resolution is enough" [05:01])
- **fail_modes**:
  - 症状: 操作卡顿/顶点过多 → 原因: Voxel Size 太小 → 补救: 调大 Voxel Size [05:01]
  - 症状: 笔触锯齿/不平滑 → 原因: Voxel Size 太大 → 补救: 调小 Voxel Size [05:01]
- **rationale**: "whenever we use brushes the geometry looks smooth" — sculpting 需要足够的面数支撑笔触变形,面数不够 = 锯齿/块状 [04:31]

### S4 · Mirror Setup (Half-Model Workflow)

- **tool**: Blender / Edit Mode + Object Mode + Mirror Modifier
- **ops**:
  1. 切换到 Front View [05:31]
  2. Edit Mode → Wireframe 显示 → 激活 **X-ray** 模式(穿透选择) [05:31]
  3. 框选模型的一半(精确沿中轴线) → `Ctrl`+拖动=减选 [05:31]
  4. 按 `X` → Delete Faces [06:01]
  5. 回到 Object Mode → 添加 **Mirror Modifier** → 轴选 X(根据模型朝向可能不同) [06:01]
  6. 勾选 **Clipping** 选项 [06:01]
  7. 确认无误 → 点 modifier 的下拉箭头 → **Apply** [06:01]
- **input**: 完整对称模型(remesh 后)
- **output**: 完整模型,两侧 100% 对称
- **accept**: 两侧几何完全镜像一致(原话: "we know 100% that two sides are identical" [06:31])
- **fail_modes**:
  - 症状: 镜像后中缝有间隙 → 原因: 未勾选 Clipping / 删除面时未沿中轴 → 补救: 重新切半+确认 Clipping
  - 症状: 镜像轴错误 → 原因: 模型旋转方向不同 → 补救: 换 Y/Z 轴试 [06:01]
- **rationale**: "we can split it into the half and mirror it → do changes on one side and the other side will be mirrored → save a lot of time" [05:31]; symmetric 模型天然适合半模工作流

### S5 · Remesh Again (Post-Geometry Change)

- **tool**: Blender / Sculpt Mode → Remesh
- **ops**: 同 S3,再按一次 Remesh [06:31]
- **input**: Mirror modifier applied 后的模型(Object Mode 改了 geometry)
- **output**: 均匀网格
- **accept**: 同 S3
- **fail_modes**: 同 S3
- **rationale**: "since we did change the geometry in object mode, it will not hurt to do remsh once again" [06:31] — Object Mode 的 geometry 编辑后必须重 remesh,否则 sculpting 时网格不均匀

### S6 · Eye Removal & Sphere Replacement

- **tool**: Blender / Sculpt Mode + Object Mode
- **ops**:
  1. **Sculpt Mode**:
     - 选 Mask brush (`M` 键) → 确保 Mirror (X symmetry) 激活 [07:01]
     - 涂抹画眼区域 → Mask 菜单 → **Sharpen Mask** [08:02]
     - `Ctrl`+涂抹=擦除 mask 边缘,精确修整 [08:02]
     - Mask 菜单 → **Invert Mask** [08:02]
     - 选 **Elastic Grab** brush → 放大 → 把眼球推入头内 [08:32]
     - 选 **Inflate** brush + `Ctrl`=deflate → 向内压平 [08:32]
     - `Shift`+涂抹 = 平滑边缘 [09:02]
     - Mask 菜单 → **Clear Mask**
     - 用 Smooth brush(小半径)平滑眼窝 [09:02]
  2. **Object Mode**:
     - `Shift+A` → Mesh → **UV Sphere** [09:32]
     - 旋转 90° → 移动 + 缩放(Gizmo 或热键)到眼眶位置 [09:32]
     - 选中球体 → Object 菜单 → Set Origin → **Origin to 3D Cursor**(3D Cursor 必须在世界原点 0,0,0) [10:02]
     - 添 Mirror Modifier(X轴) → 右键 → **Shade Auto Smooth** [10:33]
     - Edit Mode → 调整位置/缩放使眼球贴合眼眶
  3. **回到 Sculpt Mode**(选中 dino): 用 Elastic Grab 微调眼眶形状 → Clay brush 膨胀眼眶周围 → Smooth 收尾 [11:03]
- **input**: 原 AI 模型自带眼球(扁平/不准确)
- **output**: 独立 UV Sphere 眼球 + 适配的眼窝 geometry
- **accept**: 眼球形状贴合眼眶,眼窝平滑(原话: "so it's look exactly as an eyeball" [11:33]; "I think we're happy with the eyes")
- **fail_modes**:
  - 症状: mask 涂抹超出眼区域 → 原因: 画笔太大/手不稳 → 补救: `Ctrl`+涂抹擦除 + Sharpen Mask 收紧 [08:02]
  - 症状: 镜像不工作 → 原因: X symmetry 未激活 / 3D Cursor 未归零 → 补救: 检查 sculpt mirror 开关 + 确认 3D Cursor = (0,0,0) [10:02]
- **rationale**:
  - Invert mask → 保护区外,只操作眼区域 → "the mask area will basically not affected by any brushes" [08:02]
  - Origin to 3D Cursor at world origin → "so we can set a mirroring correctly" [10:02]
  - 独立 sphere 取代 AI 眼球: 更精确可控

### S7 · Teeth Removal & Cube-Based Reconstruction

- **tool**: Blender / Sculpt Mode + Edit Mode + Object Mode
- **ops**:
  1. **Mask teeth**(Sculpt Mode):
     - Box Mask 工具 → 框选牙齿区域 [11:33]
     - 切换到普通 Mask brush 补涂细节 + `Ctrl`擦除溢出 [12:03]
     - Invert Mask → **Line Project** brush → 拖动切掉牙齿 geometry [12:34]
     - 平滑切口 → Clear Mask [12:34]
  2. **Dynamic Topology 修 artifact**(Sculpt Mode):
     - 激活 **Dyntopo** [13:04]
     - Clay brush + `Ctrl`=inflate 膨胀区域 → `Shift`=smooth [13:04]
     - Draw Sharp brush + `Ctrl`=刻画分割线 [13:04]
     - **注意**: 启用 Dyntopo 前→确保所有 modifier 已 Apply [13:34]
     - 完成后 **禁用 Dyntopo** [14:04]
  3. **Create teeth**(Object Mode → Edit Mode):
     - `Shift+A` → Mesh → **Cube** [14:04]
     - Edit Mode → 选中顶面 → `X` → Delete Faces [14:35]
     - 缩放整体 → 移动定位到嘴部 [14:35]
     - 添加 **Subdivision Surface modifier**(Levels = 2) [14:35]
     - 右键 → **Shade Auto Smooth** [14:35]
     - Edit Mode: 缩放底面多边形,拉伸塑形 [15:05]
     - 底部视角检查贴合 [15:05]
     - Edit Mode 内 **Shift+D** 复制 → `G` 移动 / `S` 缩放 → 逐一摆放 [15:35]
     - 给 teeth object 添加 Mirror Modifier(X轴) [15:35]
- **input**: AI 模型的扁平/模糊牙齿
- **output**: 独立 cube 改的 3D 牙齿 + 干净牙龈区域
- **accept**: 牙齿形状拟合口腔,无残留 artifact(原话: "our teeth are ready" [15:35])
- **fail_modes**:
  - 症状: Dyntopo 后 artifact 仍在 → 原因: modifier 未 apply 就开 Dyntopo → 补救: Apply all modifiers → 重开 Dyntopo [13:34]
  - 症状: 操作严重卡顿/冻结 → 原因: Dyntopo 持续增加面数 → 补救: 关掉 Dyntopo,只在需要加几何时开 [14:04]
  - 症状: 牙齿成独立 object → 原因: 在 Object Mode 下 duplicate → 补救: 必须在 Edit Mode 内 `Shift+D`(geometry 在同一 object 内) [15:35]
- **rationale**:
  - Dyntopo: "recalculates the mesh and amount of polygons dynamically when you actually work with it" [13:34] — 可在指定区域动态加面,不浪费全局面数
  - "be careful. Use Dtopo only when you really adds more geometry because it will constantly increase the amount of polygons and that might result to into freezes" [14:04]
  - Cube → Subdivision 造牙: 比 sculpt 从头捏更快,且保持硬表面感
  - Edit Mode duplicate → "create additional geometry within the object not another object" [15:35]

### S8 · Pattern / Stripes Rework

- **tool**: Blender / Sculpt Mode
- **ops**:
  1. **Neck & Body stripes**(重画):
     - Smooth brush → 平滑 neck 过渡区 [16:35]
     - 用 Smooth brush 抹掉原有条纹(加高 strength) [16:35]
     - **Draw Sharp** brush → 从中间轴线开始画新条纹(对称) [17:06]
     - **Pinch** brush → 收窄线条 [17:06]
     - Smooth + 低 strength → 柔化 [17:06]
  2. **Tail pattern**(延伸+新画):
     - Elastic Grab → 先整形尾巴轮廓 [17:36]
     - Draw Sharp → Stroke 菜单设为 **Line** 模式 [17:36]
     - 画线(Line stroke 比手动 Space stroke 有时更准) [18:06]
     - Smooth(low strength) → Pinch 收窄 [18:06]
  3. **细节增强**:
     - **Crease** (Sharp) brush → 加深连接处("connect a little bit deeper") [18:37]
- **input**: AI 生成的不准确/模糊条纹
- **output**: 手绘清晰条纹,对称且突出
- **accept**: 条纹比原来更准确、更突出(原话: "look how better it looks now" [17:06]; "the pattern is more prominent" [19:37])
- **fail_modes**: ∅(本步无明确"否则会出错"警告)
- **rationale**:
  - 先 smooth 抹掉再重画 → AI 条纹不可靠,重画比修更可控 [16:35]
  - 从中间开始画 → 对称模型只需画中线,镜像自动完成 [17:06]
  - Line stroke mode → "sometimes easier than draw the line manually" [18:06]
  - Pinch 收窄 → 条纹更锐利,不像 AI 生成的模糊 blob

## cross_cutting

### 快捷键体系
| 键 | 位置 | 功能 |
|---|---|---|
| `F` | Sculpt Mode | 按住+拖动→调笔刷大小 |
| `M` | Sculpt Mode | 激活 Mask brush |
| `Shift` | Sculpt Mode (任何 brush) | 临时切换 Smooth |
| `Ctrl` | Sculpt Mode (任何 brush) | 反转当前 brush 效果(inflate↔deflate; add mask↔erase mask) |
| `Shift+A` | Object Mode | 添加 Mesh 基元 |
| `X` | Edit Mode | 删除(面/边/顶点) |
| `A` | Edit Mode | 全选 |
| `G` | Edit Mode | 移动(Grab) |
| `S` | Edit Mode | 缩放 |
| `Shift+D` | Edit Mode | 复制(同 object 内) |
| `~`(tilde) | 任意 | 视图饼菜单 |
| 滚轮 | 任意 | 旋转相机 |
| 滚轮+Shift | 任意 | 平移相机 |

### 通用心法
1. **半模工作流**: 对称模型切半→mirror modifier→只做一侧,省一半工时 [S4]
2. **先 remesh 再 sculpt**: Object Mode 改 geometry 后必重 remesh,否则网格不均匀 [S5]
3. **Smooth via Shift**: 永远不必切 brush — 按住 Shift 就是 smooth,松手回到当前 brush [09:02]
4. **Ctrl = invert**: 贯穿 mask 和所有 brush — inflate/deflate,add/erase mask 都靠 Ctrl [07:32]
5. **AI 模型的质量瓶颈**: 眼球→换 sphere、牙齿→换 cube+subdivision、条纹→擦掉重画、爪子→crease — 大部分 AI 特征靠**重建**而非**修补**更快更好

### 反模式/陷阱
- **Dyntopo 滥用**: 只加面时开,平常关 — 不关=面数爆炸→卡死 [14:04]
- **开 Dyntopo 前忘 apply modifier**: 必先 apply,否则 Dyntopo 在错误基础上计算 [13:34]
- **Mirror axis 盲目照抄**: 视频用 X,你的模型朝向可能不同→Y/Z 都要试 [06:01]
- **Duplicate 在 Object Mode**: 会生成独立 object→要改的 teeth 应在 Edit Mode 内 Shift+D [15:35]
- **3D Cursor 不在原点**: mirror 会歪→Set origin 前先归零 cursor [10:02]
